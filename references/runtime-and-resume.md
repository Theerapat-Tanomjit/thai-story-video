# เครื่องมือและการทำงานต่อ

## ตรวจความพร้อม

สกิลนี้ใช้คำสั่ง Markdown และไฟล์อ้างอิงร่วมกันได้ แต่การค้นพบสกิลและเครื่องมือขึ้นกับ agent และเวอร์ชัน ไม่รับรองว่าทดสอบครบทุก agent

- ระบุตำแหน่งรากสกิลจากไฟล์ SKILL.md ที่อ่าน และรากงานจากโครงการปัจจุบัน แก้ relative links จากไฟล์ที่อ้างถึง ไม่ใช้ path ของผู้สร้าง
- ตรวจ FFmpeg, ffprobe, libass และฟอนต์ไทยก่อนเรนเดอร์ การสร้างภาพต้องมีเครื่องมือภาพหรือไฟล์ผู้ใช้ ส่วนเสียงใช้ไฟล์ผู้ใช้หรือ TTS ที่เข้าถึงได้
- ใช้เครื่องมือภาพและเสียงของ environment นั้น ไม่สมมติว่ามี imagegen, Google AI Studio API หรือ API key
- หากไม่มีเครื่องมือ ให้ส่งบท storyboard และ prompt พร้อมระบุไฟล์ที่ขาด ห้ามอ้างว่าสร้างสื่อหรือเรนเดอร์สำเร็จ
- ชุดนี้ไม่มีโปรแกรม pipeline, โมเดล, ฟอนต์ หรือสื่อแบรนด์รวมมา ไม่จำเป็นต้องเพิ่ม provider adapter เพื่ออ่านสกิล

## Checkpoint

บันทึก TASK_PROGRESS.md ในรากงานหลังจบแต่ละระยะ: เป้าหมาย ข้อกำหนด สิ่งที่อนุมัติแล้ว ไฟล์และเวอร์ชันจริง เครื่องมือที่ใช้ ผลตรวจ งานค้าง และขั้นตอนถัดไป ไม่บันทึก secrets

ก่อนแก้ไฟล์ที่มีอยู่ สำรองไฟล์นั้นไป backups/<timestamp>/ โดยคงโครงสร้าง ตรวจว่าคัดลอกสำเร็จแล้วจึงแก้ ห้ามลบหรือเขียนทับชุดสำรอง เก็บไฟล์ผลลัพธ์เป็นเวอร์ชันใหม่

เมื่อทำงานต่อ อ่าน checkpoint ตรวจไฟล์จริง และตรวจ git status/diff หากเป็น Git repo อย่ารันงานสำเร็จซ้ำหรือเขียนทับไฟล์ที่อนุมัติแล้ว การมี checkpoint ไม่ทำให้งานกลับมารันอัตโนมัติ

ใช้ subagent เฉพาะเมื่อคำสั่งหรือผู้ใช้อนุญาต แบ่งไฟล์เจ้าของชัดเจน และให้ตรวจผลรวมก่อนส่ง
