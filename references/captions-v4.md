# ซับ V4

ขนาด ASS 108 คำหรือกลุ่มคำสั้นที่กำลังพูดเด้งและเปลี่ยนสี คำอื่นขาว สีเหลือง #FFD869 ในวลีเน้น ฟ้าอ่อน #94E5FF ในวลีทั่วไป ไม่มีแผ่นหลัง

ใช้ Noto Sans Thai Bold ขอบ 5 เงา 2 เด้ง 96% → 112% ใน 65 ms → 100% ใน 145 ms ขนาดฐาน 108 วลียาวแบ่งบรรทัดตามขอบเขตคำ คุมความกว้างรวมตอนเด้งภายใน 930 px บน 1080×1920 จุดกลาง x=500 บรรทัดเดียว y=1518 สองบรรทัด y=1460,1585 ปรับได้เพื่อหลบภาพสำคัญ

เมื่อใช้ Pillow วัดช่องไฟสำหรับ libass ให้ปรับความกว้างด้วย font_size / (ascent + descent) และตรวจภาพเรนเดอร์จริง ไม่ใช้ความกว้าง Pillow ตรง ๆ ระวังตัวอักษรและขอบชนกันระหว่างเด้ง

เรื่องใหม่ต้องใช้บทและเวลาใหม่ ไม่คัดลอกเวลาเดิมหรือการแก้ ASR โดยไม่ตรวจเสียงจริง

ภาพหลักใช้ไฟล์ไม่มีซับฝัง เสียงบรรยายต่อเนื่อง ต่อท้ายเฉพาะเมื่อผู้ใช้มีไฟล์และต้องการใช้

SRT เก็บข้อความกับเวลาเท่านั้น สีและเด้งอยู่ใน ASS/MP4 ไม่อ้างว่าตรวจมือถือหรือเผยแพร่แล้วหากยังไม่มีหลักฐาน
