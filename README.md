# thai-story-video

สกิลสำหรับให้ AI agent ช่วยผลิตคลิปเรื่องเล่าภาษาไทยแนวตั้ง: บทเต็ม, storyboard, prompt ภาพ, เสียงต่อเนื่อง, ซับ V4, ปก และการตรวจวิดีโอ

## สิ่งที่ได้รับ

- `SKILL.md`: ขั้นตอนและข้อกำหนดการผลิต
- `references/editing-preset.json`: ค่าตัดต่ออ้างอิง
- `references/captions-v4.md`: รูปแบบซับและข้อจำกัดการวัดข้อความ
- `references/runtime-and-resume.md`: ความพร้อมเครื่องมือ การสำรอง และ checkpoint

นี่เป็น instruction skill ไม่ใช่แอปสร้างวิดีโออัตโนมัติ ไม่มี API key, โมเดล, ฟอนต์, สคริปต์เรนเดอร์ หรือสื่อแบรนด์แนบมา

## เริ่มลอง

ดาวน์โหลด repository แล้ววางโฟลเดอร์ `thai-story-video` ทั้งชุดในตำแหน่งสกิลที่ agent รุ่นของคุณรองรับ โดยให้ SKILL.md อยู่ในโฟลเดอร์เดียวกับ references ไม่คัดลอกเฉพาะ SKILL.md และไม่เขียนทับสกิลเดิมโดยไม่สำรอง

หาก agent ไม่ค้นพบสกิล ให้เปิด SKILL.md และสั่งให้อ่านไฟล์อ้างอิงที่เชื่อมไว้โดยตรง วิธีนี้ไม่รับรองความสามารถเรียกเครื่องมือของ agent นั้น

ตัวอย่างโจทย์:

> ใช้ thai-story-video ช่วยทำคลิปภาษาไทยเรื่องทำไมท้องฟ้าจึงเป็นสีฟ้า ความยาวประมาณ 45 วินาที เริ่มจากบทเต็ม คำสั่งน้ำเสียงแยก และ storyboard ตรวจเครื่องมือก่อนสร้างภาพและวิดีโอ ใช้ชื่อช่องของฉัน ไม่ต่อ outro หากไม่มีไฟล์

การเรนเดอร์ต้องมี FFmpeg/ffprobe พร้อม libass และฟอนต์ไทย เช่น Noto Sans Thai รวมถึงภาพกับเสียงจริง หากไม่มี ให้ agent เตรียมบทและ prompt ก่อน

## ค่าเริ่มต้น

MP4 H.264, yuv420p, 1080×1920, 30fps, AAC, faststart ซับ ASS ขนาด 108 และเด้งคำตามเสียงจริง ส่ง SRT เพิ่มได้ แต่ SRT ไม่เก็บสีและ animation

ปก Facebook 1080×1920 และ TikTok 1080×1440 เป็นแม่แบบของ workflow นี้ ต้องตรวจข้อกำหนดและ crop จริงก่อนโพสต์ ไม่ใช่คำรับรองว่าทุกหน้าจอรองรับเหมือนกัน

## ความเข้ากันได้

คำสั่งไม่ผูกกับชื่อ provider ภาพหรือเสียง ใช้กับ agent ที่อ่าน Markdown และไฟล์อ้างอิงได้ ส่วนการติดตั้งอัตโนมัติและการเรียกเครื่องมือขึ้นกับแต่ละผลิตภัณฑ์ ยังไม่ได้ทดสอบ end-to-end บน Claude Code, Gemini CLI หรือ OpenCode

## การสำรองและสิทธิ์

ก่อนปรับไฟล์เดิม ให้สำรองแบบระบุเวลาเสมอ และเก็บ TASK_PROGRESS.md ในโครงการงานเพื่อทำต่อ ชุดสำรองส่วนตัวไม่อยู่ใน repository นี้

อนุญาตให้นำคำสั่งและ preset ใน repository นี้ไปใช้ ดัดแปลง และแจกต่อได้ตาม LICENSE (MIT) สิทธิ์นี้ไม่ครอบคลุมโลโก้ เสียง ภาพ วิดีโอของช่องต้นฉบับ หรือสื่อและบริการภายนอก ผู้ใช้ต้องจัดหาไฟล์และสิทธิ์ของตนเอง
